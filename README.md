# NEHA's Portfolio Website

A beautiful, beginner-friendly portfolio website built with HTML, CSS, and JavaScript.

## Features

- ✨ Modern and responsive design
- 📱 Mobile-friendly navigation
- 🎨 Smooth animations and transitions
- 🚀 Fast loading and optimized
- 📝 Well-commented code for easy learning

## Files Structure

```
wad_portfolio/
├── index.html      # Main HTML structure
├── style.css       # All styling and design
├── script.js       # Interactive features
└── README.md       # This file
```

## How to Use

1. **Open the website**: Simply open `index.html` in your web browser
   - Double-click the file, or
   - Right-click → Open with → Your preferred browser

2. **Edit the content**: 
   - Open `index.html` in any text editor
   - Modify the text, sections, or information as needed
   - Save and refresh your browser to see changes

3. **Customize the design**:
   - Open `style.css` to change colors, fonts, spacing, etc.
   - All colors are defined with easy-to-find values (like `#667eea`)

4. **Add interactivity**:
   - Open `script.js` to add or modify JavaScript features
   - Code is well-commented for beginners

## Sections Included

1. **Home/Hero** - Introduction section
2. **About** - Personal information
3. **Education** - Educational background with timeline
4. **Achievements** - Awards and accomplishments
5. **Skills** - Technical and soft skills
6. **Contact** - Contact information

## Customization Tips

### Change Colors
In `style.css`, look for color values like:
- `#667eea` - Primary purple color
- `#2c3e50` - Dark blue/navy
- `#ffd700` - Gold/yellow accent

### Add New Sections
1. Copy an existing section in `index.html`
2. Update the content
3. Add corresponding styles in `style.css` if needed

### Modify Navigation
- Add/remove items in the `<ul class="nav-menu">` in `index.html`
- Make sure the `href` matches a section `id`
